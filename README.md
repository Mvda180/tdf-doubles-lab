# TDF Doubles Lab

Een zelfstandige webapp van The Darts Family. Gooi op je eigen bord en registreer je resultaat in de app.

- Instaptest van 36 darts, met een uitsplitsing per double.
- Dubbelbingo, Red je finish en Pro Checkout Sprint, elk op drie niveaus.
- Sessies en resultaten worden lokaal in de browser bewaard.

## GitHub Pages

Plaats deze bestanden in de hoofdmap van de repository. Kies bij **Settings → Pages → Build and deployment** voor **Deploy from a branch** en selecteer **main** en **/ (root)**. De app heeft geen buildstap of server nodig.

Open lokaal `index.html` of gebruik een lokale statische webserver.
